Examples
####################################################################

The purpose of this repository is to :
    - **explain**, how a feature interacts with components external to BNK, pointing to official BNK documentation `here <https://clouddocs.f5.com/bigip-next-for-kubernetes/latest/>`_
    - **share an example** of a tested deployment to show **How To** configure the feature with an example

Because this repository is community supported, a shared example will be tested in a the version specified
